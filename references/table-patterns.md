# Case retrieval and adaptation

Run index_cases.py after adding case metadata, then retrieve_cases.py with explicit --columns, --type and repeated --feature flags. Scores prioritize structural feature matches (+8 each, -4 for a missing requested feature), table type (+12 match/-4 mismatch), and proximity of column count (6-absolute difference, floored at -10). Unknown width costs 6; ties use case_id. Scores explain similarity, not a guarantee that a pattern is suitable. Read the top candidates and their caveats before copying design.

Observed corpus features: grouped_headers, multiple_datasets, uncertainty, component_matrix, row_groups, multirow, nested_headers, coverage_symbols, rotated_headers, precomputed_rank, best_second, deltas, custom_columns, urls. Corpus metadata is manually inspected; package inference is heuristic. Local snapshots have unknown rights and remain unverified. `case.json` contains sources with exact hashes, organization, rationale, caption/label/alignment conventions, rights, template and actual verification states. New cases use the same fields. Store originals separately from adaptations; record derived_from, formulas and evidence. Never modify the original snapshots to normalize style.

Additional patterns supported through original synthetic examples/guidance: cross-dataset transfer (separate source/train and target/test labels), efficiency tradeoffs (accuracy vs latency/parameters with independent directions), mean/std and CI display. These patterns are not claimed as observed in the supplied corpus. Formal statistical significance remains author-provided; do not infer it from score order or overlapping intervals.

To learn from a future example, capture its provenance and rights, snapshot bytes, create metadata, retrieve against a known query and compile with its real macros. Inspect at final size before marking it verified. Keep incomplete candidates pending. Adding data to a local library is authorized when the user asks to learn that example; changing stable scripts/rules uses the RSI gate.
